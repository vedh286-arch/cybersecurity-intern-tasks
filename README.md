# Task 1: Scan Your Local Network for Open Ports

Cybersecurity Internship - Elevate Labs

## Overview
I scanned my local network (192.168.136.0/24) with Nmap using a TCP SYN scan and found 7 open ports on 192.168.136.1 (135, 139, 445, 902, 912, 4343 and 4449). I also captured a small scan in Wireshark to see how a SYN scan works.

## Tasks done
- Scanned the network with Nmap (`nmap -sS`)
- Noted the open ports and researched the services
- Identified the security risks
- Saved the scan results as a text file
- Captured and analyzed the scan in Wireshark

## Tools
Nmap, Wireshark
